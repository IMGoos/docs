## Добро пожаловать

API VangardPay позволяет мерчантам принимать платежи и управлять ими. Поддерживаются два сценария интеграции: прямая Host-to-Host интеграция и использование готовой платежной страницы.

**Аутентификация:** 
Для всех запросов к API, требующих авторизацию, используйте заголовок `X-API-Key` с вашим секретным ключом.

**Вебхуки:** 
Система отправляет POST-уведомления на ваш `callbackUrl` при изменении статуса. Подпись формируется как `sha256(invId + status + amount + timestamp, callbackSecret)`.

## Доступные методы

Для работы с заказами, зачислением средств, контролем баланса и апелляциями используйте навигацию меню слева.
